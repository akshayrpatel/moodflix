  * `void releaseLock(String eventId)`: Deletes key on failure for retry enablement.

* **`VectorShiftStrategy`**: Strategy interface for vector algebra.
* **`WeightedNormalizedVectorShiftStrategy`**: 15-line pure Java primitive `float[]` implementation:
  * Directional weighted shift: $V_{\text{shifted}} = V_{\text{user}} + (w \times V_{\text{movie}})$.
  * Epsilon check ($10^{-9}$) to guard against zero-division / NaN corruption.
  * L2 normalization to unit length ($1.0$) for cosine similarity.
* **`WeightedNormalizedVectorShiftStrategyTest`**: Unit test verifying 384-dimension constraints and unit-length output.

## 2. Key Architectural Decisions Recorded

1. **Immediate Stream Processing over Micro-Batching:**
   Prioritizes instant feed responsiveness ($<100\text{ms}$). Micro-batching remains the documented high-scale evolution.
2. **Two-Phase Claim-Mutate-Confirm Pattern:**
   * **30-second Claim TTL:** Protects against crashing workers (auto-expires so retries aren't blocked).
   * **24-hour Persist TTL:** Protects against duplicate network retries.
   * **Compensating Delete:** Catch block deletes lock on DB failure to allow Kafka retries.
3. **Pure Java Vector Math vs. Third-Party Libraries:**
   Chosen for sub-100ns execution, zero heap allocations, JVM SIMD vectorization, and zero extra dependency bloat.
4. **Idempotency Naming Standard:**
   Adopted distributed lock convention: `acquireLock`, `persistLock`, `releaseLock`.
